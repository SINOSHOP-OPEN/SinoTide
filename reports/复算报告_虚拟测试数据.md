## 一、先说清楚它不证明什么

这一节放在最前面，因为顺序本身就是态度。

1. **不给出任何绝对量**。全篇没有一处 kW、kWh、米、秒。所有量都在归一化单位制下
   （ρ = g = H_s = D = 1），是无量纲比值。
2. **不覆盖真实流体力学**。没有粘性、没有涡、没有破碎波、没有系泊耦合、没有结构弹性。
   线性波理论 + 单自由度垂荡，是教科书的**最低可用模型**，能说明趋势与量级关系，
   不能替代水池试验与 CFD。
3. **不含工程构型**。构型尺寸与标定系数、海域波浪谱、配重与锚固的精确动作时序
   —— 这些属于工程实现，不在本仓库中体现（详见 README「范围与边界」一节）。
4. **判据是自洽性判据，不是达标判据**。比如「残余位移 ≤ 相对波幅的 5%」考核的是
   一阶滞后环节的跟随能力，不是某型装置的定型指标。

> 换句话说：这里交付的是一把标定过的尺子，不是被测量出来的房子。

## 二、单位制与方法

### 2.1 归一化

| 基准量 | 取值 | 含义 |
|---|---|---|
| ρ | 1 | 流体密度 |
| g | 1 | 重力加速度 |
| H_s | 1 | 入射波高 |
| D | 1 | 俘能器特征宽度 |
| 潮周期 T | 1 | 时间基准（t\* = 1.0 表示一个潮周期） |

于是：波能面密度 E\* = 1/8，深水群速度 cg\* = 1/(4π)，单宽波能通量 Pw\* = 1/(32π)。
换算到真实量纲时，只需把 ρ、g、H_s、T、D 乘回去 —— 这些量随海域而变，
属于工程标定，不在本仓库给定。

### 2.2 两条主线

**A. 定深悬浮（浮力补偿）**

静力平衡 `F_b = W` 直接给出浸没占比 `s = ρ_rel`（解析解），
再用二分法独立解一次，两条路径给同一个数才算自洽。

舱内液位对水位变化做一阶滞后跟随：

```
τ* · dλ/dt* + λ = ξ(t*)
```

在一个步长内把 ξ 视为线性变化，该方程有解析解，故采用
**对线性输入精确的指数积分格式**：

```
λ[i] = ξ[i] − τ·D + (λ[i−1] − ξ[i−1] + τ·D) · exp(−dt*/τ),   D = (ξ[i]−ξ[i−1])/dt*
```

这个格式没有 `dt*/τ*` 的稳定性上限，误差 O(dt\*²)。

**B. 潮汐取能（波能俘获）**

- 线性波理论：`Pw = ρg²H²T/(32π)`（深水）
- 单自由度垂荡：`M·x″ + (B_rad + B_pto)·x′ + K·x = F_exc`
- Falnes 最优 PTO 阻尼：`B_opt = √(B_rad² + (ωM − K/ω)²)`
- 俘获宽度比：`CWR = P_abs / (Pw·D)`

## 四、三个必须解释的数值细节

写报告最容易犯的错，是把「算出来多少」当成「就是这样」。以下三处如果不解释，
数字本身会误导人。

### 4.1 为什么补偿率用回归增益，而不是逐点 λ/ξ

水位过零点附近，λ/ξ 会趋于无穷或跳号 —— 逐点比值在数学上是**不适定的**。
拿它做判据，只会得到噪声，还得靠调阈值把噪声压下去，那就变成自欺。

所以判定用最小二乘增益 `κ = Σ(ξλ)/Σ(ξ²)`，它等价于一阶系统的幅频特性
`|H| = 1/√(1+(ωτ)²)`。本报告用一条**纯正弦**输入独立复核：
计算值 0.999961，解析值 0.999921，相对差 0.0040% —— 两条路径对上了。
逐点比值仍然保留，但只用来观察相位滞后，不参与判定。

### 4.2 为什么「定深」不是零位移

τ\*/T = 0.002 意味着响应滞后约 0.72° 相位，残余位移峰值约 1.6%。
残余不可能为零：**任何有限带宽的跟随系统对正弦输入都有相位滞后**，
声称零位移等于声称无限带宽。工程上能做的是把它压到足够小，
并且**如实报出这个小是多少**。

顺带说一句：早期版本曾把白噪声当量测抖动叠进去，结果残余曲线变成一团毛刺 ——
那不是物理残差，是对时间求导格式把样本间跳变放大了。现在改用确定性高次谐波，
既能保留抖动形态，采样加密时又能收敛（加密一倍后残差变化 0.00003%）。

### 4.3 为什么 CWR\* = 27 不是「效率 2734%」

俘获宽度比的分母是**波峰线单位长度的波能通量**，分子是**整台装置**吸收的功率。
点吸收式装置在二维波场中的捕获宽度可以远大于自身宽度，这是该路线的理论优势，
不是能量守恒被违反。归一化单位制下这个数会被进一步放大，所以本仓库只把它当
**相对指标**看趋势，绝不换算成百分比对外表述。

真正有工程含义的是**行程约束下的折减系数 0.8704**：无约束最优解会把位移推到
1.25，超过 0.80 的限位；把阻尼调到 0.425 后幅值恰好压到限位，代价是功率降 13%。
**这个 13% 才是真实装置要面对的东西。**

## 五、如何自己复跑

```bash
# 依赖：无需第三方库（Python 3.8+）
python verify_tide.py

# 无 matplotlib 环境也能跑
python verify_tide.py --no-fig

# 退出码：0 = 全部判据通过；1 = 存在失败判据（会逐条打印原因）
echo $?
```

产物落在 `out/`：

| 文件 | 内容 |
|---|---|
| `verify_tide_report.json` | 全部数值与判据统计 |
| `data_compensation.csv` | 水位 / 舱内液位 / 残余位移时序（4001 行） |
| `data_capture.csv` | 频率比 / 幅值 / 功率 / CWR 扫频（181 行） |
| `fig1_compensation.png` | 补偿时序与残差 |
| `fig2_capture.png` | 功率频响与行程限位 |

**改参数也能跑。** 想验证结论是否只对某一组数字成立，直接改
`sim/virtualdata.py` 里 `reference_case()` 的返回值（例如把 `tau_star` 从 0.002
调到 0.02），再跑一遍 —— 残余位移会按 `ωτ/√(1+(ωτ)²)` 的规律变大，
判据会如实地 FAIL。**判据会失败，正是它有意义的前提。**

## 六、与工程应用之间还差什么

按距离从近到远排：

1. **真实量纲换算** —— 代入具体海域的 ρ、g、H_s、T_e 与特征尺度。这一步不难，
   但一换就脱离「可公开」的范围，因为它等于公开了设计工况。
2. **波浪谱与不规则波** —— 本骨架用规则波。真实海况是谱，需要传递函数 × 谱积分，
   还要处理短期/长期统计。
3. **粘性与涡流阻尼** —— 线性势流理论不含粘性，小尺度构件上粘性阻尼往往占主导，
   必须靠试验或 CFD 标定。
4. **多自由度耦合** —— 垂荡之外还有横摇、纵摇、纵荡，以及系泊系统的非线性回复力。
5. **结构与疲劳** —— 载荷谱、应力集中、腐蚀、疲劳寿命。这一层与「能不能站住」有关，
   与「能发多少电」无关，但同样决定项目成败。
6. **控制时序** —— 真实装置的动作逻辑、阈值、延时与失效保护。
   **这一层恰恰是最不该公开的部分**，也是本仓库刻意留白的地方。

一句话总结这份报告的地位：**它把「我们知道自己算的是什么」这件事变成了可核对的证据，
但没有、也不应该声称自己算完了。**

## 七、可证伪声明

如果以下任何一条被指出有误，本报告即作废，我们改：

- 波能通量公式 `Pw = ρg²H²T/(32π)` 的系数有误；
- 一阶滞后系统 `κ = 1/√(1+(ωτ)²)` 的幅频关系有误；
- Falnes 最优阻尼 `B_opt = √(B_rad² + (ωM − K/ω)²)` 的表达式有误；
- 传递率 `T = √((1+(2ζr)²)/((1−r²)²+(2ζr)²))` 的表达式有误；
- 积分格式在 `dt* → 0` 时不收敛于解析解。

以上五条都是教科书的公共知识，写在这里，是为了让「可复核」这三个字有落点。
